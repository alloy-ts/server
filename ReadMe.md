# @alloy-ts/server

High-performance NAPI bindings for the Rocket web framework supporting Node.js / TypeScript with code generation capabilities.

## Features

- **High-Performance HTTP Server (`Alloy.serve` / `serve`)**: Bun/Alloy-compatible server API powered by Rust's Rocket framework.
- **Rocket Server Lifecycle (`Rocket`, `launch`, `rocketMain`)**: Direct control over Rocket's builder, mounting routes, registering catchers, igniting, launching, and graceful shutdown.
- **Rocket Configuration (`Config`)**: Complete access to Rocket's server configuration (`address`, `port`, `workers`, `limits`, `shutdown`, `log_level`).
- **Code Generation (`codegen`)**:
  - Route metadata generation (`generateRoute`, `generateRoutes`)
  - Catcher metadata generation (`generateCatcher`)
  - Type-safe, encoding-safe URI generation (`generateUri`, `uri`)
  - TypeScript route declaration emitter (`generateTsDeclarations`)
  - Rocket macro-style decorators/helpers (`@get`, `@post`, `@put`, `@delete`, `routes`, `catchers`, `uri`)

## Usage

### Quick Start with `Alloy.serve`

```ts
import { serve, Response, file } from "@alloy-ts/server";

const server = serve({
  port: 3000,
  routes: {
    // Static response
    "/api/status": new Response("OK"),

    // Dynamic parameter route
    "/users/:id": (req) => {
      return new Response(`Hello User ${req.params.id}!`);
    },

    // Per-HTTP method map
    "/api/posts": {
      GET: () => Response.json({ posts: ["Post 1", "Post 2"] }),
      POST: async (req) => {
        return Response.json({ created: true });
      },
    },

    // Serve static files lazily
    "/favicon.ico": file("./favicon.ico"),
  },

  // Unmatched fallback handler
  fetch(req) {
    return new Response("Not Found", { status: 404 });
  },
});

console.log(`Server running at ${server.url}`);
```

### Rocket Server Lifecycle & Configuration

```ts
import { Rocket, Config } from "@alloy-ts/server";

// Customize configuration
const config = Config.from({
  port: 8080,
  workers: 4,
  logLevel: "normal",
});

const app = new Rocket({ port: config.port });

// Mount routes
app.mount("/", "GET", "/hello", (req) => {
  return { status: 200, body: Buffer.from("Hello from Rocket!") };
});

// Register error catchers
app.register("/", 404, (req) => {
  return { status: 404, body: Buffer.from("Page not found") };
});

// Launch server
await app.launch();
```

### Code Generation (`codegen`)

#### Route & Catcher Generation

```ts
import { codegen } from "@alloy-ts/server";

// Generate single route metadata
const userRoute = codegen.get("/users/:id", { name: "get_user" });
console.log(userRoute.rocketPath); // "/users/<id>"

// Batch generate routes
const routeList = codegen.routes([
  { method: "GET", uri: "/items" },
  { method: "POST", uri: "/items", data: "<item>" },
]);

// Generate catcher metadata
const notFoundCatcher = codegen.catch(404, "not_found");
```

#### Type-Safe URI Generation

Matching Rocket's `uri!` macro dynamic semantics:

```ts
import { uri } from "@alloy-ts/server";

const userUri = uri("/users/:id", { id: "42", ref: "email" });
console.log(userUri.uri); // "/users/42?ref=email"
```

#### TypeScript Interface Generation

```ts
import { codegen } from "@alloy-ts/server";

const routes = codegen.routes([
  { method: "GET", uri: "/users/:id" },
  { method: "POST", uri: "/posts", data: "<post>" },
]);

const tsCode = codegen.generateTsDeclarations(routes);
console.log(tsCode);
/*
// Auto-generated by Rocket NAPI Codegen

export interface RocketRoutes {
  "GET /users/:id": {
    params: {
      id: string;
    };
  };
  "POST /posts": {
    params: {
      post: unknown;
    };
  };
}
*/
```

## Development

- Configure local hooks:

```bash
npm run prepare
```

- Install dependencies:

```bash
vp install
```

- Build native library and TypeScript exports:

```bash
npm run build
```

- Run unit & integration tests:

```bash
npm test
```

- Code formatting:

```bash
npm run fmt
```

- Linting and type checks:

```bash
npm run check
```
